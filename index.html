About Trackus

Trackus is a demonstration of intelligent college bus tracking and commute estimation. It provides a map, simulated bus movement, traffic-based ETA estimates, and bus status monitoring.

This GitHub Pages version uses a distance-and-speed calculation. It does not execute the Python machine-learning model or provide live traffic or GPS data.
